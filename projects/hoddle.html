HODDLE Studios

A six-person game studio with one motto: play with purpose. Our game COMMUHELP is a co-op game about saving the environment. I designed the interfaces, the studio website and a merch line, and kept the team moving as facilitator.

RoleUI/UX design, merch design, facilitator
Team6 people
ToolsFigma, Canva
When2024 – 2025

The crew

Everyone wore more than one hat. Mine were the UI and UX of the game and website, plus facilitating our meetings so decisions actually got made.

  • Huda Imran Project Leader, Product Designer, Story Writer
  • Omar El Sadek UI Designer, UX Designer, Facilitator
  • David Manuel Tester, Marketing, Video Editor
  • Dylan Duario Game Developer, Game Manager, Video Editor
  • Luke Domingo UI Designer, UX Designer, Marketing
  • Eyron Araza Web Developer, Game Artist, Game Designer

Play with purpose

The studio identity is playful on purpose: chunky green type, a little astronaut mascot and a space theme that carries from the logo through the website and every slide.

Merch

To help fund the game I designed a merch line: hoodies and tees, character keychains and plushies of the four pixel heroes, all in the game's colours.

What's next
